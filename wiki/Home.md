# Welcome to the MooNsPlanner Wiki! 🌙

MooNsPlanner is a fully self-hosted travel planning and exploration platform. Here you will find detailed documentation on how to deploy, configure, and use the application.

## 📖 Contents

- [Installation](Installation) - Detailed guides for running via Docker, from sources, or Kubernetes.
- [Architecture](Architecture) - Overview of the tech stack, monorepo structure, and backend services.
- [Configuration](Configuration) - Guide to environment variables, OIDC, and other settings.
- [Development](Development) - How to contribute, run tests, and develop plugins.

## 🚀 Quick Start

If you're just looking to get started quickly, check out the `start.sh` or `start.bat` scripts in the root directory!

```bash
git clone https://github.com/schowdary75/MooNsPlanner.git
cd MooNsPlanner
./start.sh
```
